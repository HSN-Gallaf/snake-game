# Snake Game

## User Stories

### Main Features:

- As a user, I want to see a landing page when I arrive at the website, so I know I am in the right place.
- As a user, I want to be able to see the instruction of the game before starting.
- As a user, I want to be able to click the arrows keys to move the snake to where I want
- As a user, I want to be able to hit the food object to increase the snake size
- As a user, I want to be able to game over message after hitting the wall or after hitting the snake body
- As a user, I want to be able to restart the game

### Wish List Features:

- As a user, I want to be able to switch between Dark and Light moods.
- As a user, I want to be able to switch between levels.
- As a user, I want to be able to hear a voice at two times: 1. after winning 2. after losing
- As a user, I want to be able to see animation after winning.
- As a user, I want to be able to see the highest score.

# Card Memory Game

## User Stories

### Main Features:

- As a user, I want to see a landing page when I arrive at the website, so I know I am in the right place.
- As a user, I want to be able to see the instruction of the game before starting.
- As a user, I want to be able to chose two boxes at a time to see if the icons match.
- As a user, I want to be able to see the time left to indicate game over
- As a user, I want to be able to see a the box change colour after choosing my two options indicating correct or incorrect.
- As a user, I want to be able to know that I have won after matching all the icons before the time finishes.
- As a user, I want to be able to restart the game.

### Wish List Features:

- As a user, I want to be able to see how many mistacks left to lose
- As a user, I want to be able to see how many mistakes has been made throw the one game.
- As a user, I want to be able to change the game mode between Dark and Light.
- As a user, I want to be able to switch between levels.
- As a user, I want to be able to pause the timer.
- As a user, I want to be able to hear a voice at Four times: 1.Correct Choice 2.Wrong Choice 3.Wining 4.Losing .
- As a user, I want to be able to see animation after winning.
